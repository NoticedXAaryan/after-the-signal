# Kenney models

The four GLB files and their shared colormap are unchanged from Kenney's [Starter Kit 3D Platformer, revision 3fa8a04](https://github.com/KenneyNL/Starter-Kit-3D-Platformer/tree/3fa8a04b1c01ab23db43123d4ce814a34c3fc7f0/models). Its README licenses the game assets under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

First Ruin uses the animated character for Mara's courier, the flag as a landmark, and two sizes of grass. Retain `Textures/colormap.png` relative to the GLB files so their materials load.
