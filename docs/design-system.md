# After the Signal design system

## Visual language

Use spruce and parchment for reading and navigation, brass for earned stars, and mint for a passing or powered state. Keep the coding surface restrained and reserve illustration for the expedition and Fieldbook. See the [brand identity](brand-identity.md) for current logo files, art, and prompts.

| Token | Value | Role |
| --- | --- | --- |
| Ink | `#172723` | Marks on light surfaces |
| Spruce | `#132322` | Navigation and icon plate |
| Parchment | `#eee4d0` | Lessons and Fieldbook |
| Brass | `#dbbd86` | Earned stars and labels |
| Signal mint | `#a9ead0` | Live status and signal arcs |

Use Georgia for headings, Segoe UI for text, and Cascadia Code or Consolas for code and counters. The beacon emblem represents a powered terminal. The legacy Java Grove illustrations remain in the art archive.

## Interaction

- The map shows one highlighted next round. A locked node keeps its number and displays a lock. Completed nodes display earned stars and can be replayed.
- Each round uses the same three steps: Briefing, Code challenge, Stars. Maintain a direct route back to the map.
- Use the short reward pop and companion hop for interaction feedback. Respect reduced-motion settings. Keep test errors direct and put jokes in character lines and the field guide.
- Keep focus visible, label icon-only controls, and preserve keyboard navigation and text alternatives for status.
